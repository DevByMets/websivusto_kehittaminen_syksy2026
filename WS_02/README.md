# WS_02 – Verkkosivuston kehittäminen

## Harjoituksen sisältö

Tässä kansiossa on WS_02-harjoitukseen liittyvät tiedostot. Harjoituksessa keskityin CSS:n perusteisiin ja siihen, miten CSS:llä muotoillaan verkkosivun sisältöä. Tämä README käsittelee vain WS_02-harjoitusta.

## Mitä tein

- Tutustuin CSS:n perusteisiin harjoituksen ohjeiden avulla.
- Harjoittelin CSS-tyylien lisäämistä verkkosivulle ja niiden vaikutuksen tarkistamista.
- Tallensin tekemäni muutokset tähän kansioon ja tarkistin lopputuloksen.

## Mitä opin

- Opin CSS:n perusteita ja sitä, miten tyylisäännöillä voidaan muuttaa verkkosivun ulkoasua.
- Harjoittelin CSS-tyylien muokkaamista ja niiden vaikutuksen tarkistamista.
- Opin, että pienetkin virheet kannattaa etsiä ja korjata järjestelmällisesti.

## Oma pohdinta

Harjoitus auttoi minua ymmärtämään CSS:n perusteita ja niiden käyttöä verkkosivun ulkoasun muokkaamisessa. Jatkossa haluan harjoitella CSS:n käyttöä lisää.
