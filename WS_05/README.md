# Responsive Layout Harjoitus

Tässä harjoituksessa harjoitellaan:

- responsiivisen sivuston rakentamista
- Responsive Imaget:n lisäämistä
- media query -sääntöjen käyttämistä
- responsiivisen navigointipalkin (navigation bar) luomista

Harjoituksen tavoitteena on tehdä sivusto, joka mukautuu erikseen esimerkiksi puhelimen, tabletin ja tietokoneen näytön kokoon.
